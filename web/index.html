Interpretation and limitations

This is an arithmetic aid for documenting reviewer judgments, not an automated appraisal. Study limitations, imprecision, and upgrade criteria require substantive methodological justification. Certainty ratings apply to an outcome and body of evidence, not individual patients.

The rating is clamped to four categories: very low, low, moderate, and high. Upgrading is available only for non-randomized evidence without other downgrades under this conventional approach.

Privacy: Input stays on this device. No analytics, API calls, or browser storage are used. Export creates a local JSON file.
